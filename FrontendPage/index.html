不上内核保护时，每次举报都要烧 AI 全链路分析；上 PPL + HVCI + 漏洞驱动阻止列表后， 只有未公开 0day 驱动打穿的 <1% 才进入 AI 深度分析。未公开漏洞驱动的黑市价 > 把它烧在外挂上的收益——这就是成本不对等。

LAYER 01

可信启动验证

TPM 2.0 远程证明。Secure Boot / VBS / HVCI / IOMMU / 驱动签名强制，全部由硬件度量、服务端重放验证，内核沦陷也伪造不了。

03

Hypervisor · VBS · HVCI / VIRTUALIZATION BASED SECURITY

Hyper-V 抢占 VT-x 后，Windows 被拆成 VTL0（普通世界）与 VTL1（安全世界）。 HVCI 在 VTL1 中裁决所有可执行页：未签名代码永远拿不到 W+X 页面——SLAT 直接拒绝。 右侧是从 WBCL 日志三条证据链判定 HVCI 真实开启的源码。

// WBCL SIPA EVIDENCE CHAIN · vbsFlags 位解析
04

WHQL 驱动签名体系 / DRIVER SIGNING CHAIN

Authenticode 内嵌签名 + Windows Catalog 目录签名双通道验证： WinVerifyTrust 走证书链到 Microsoft Root，CryptCATAdmin* 在 .cat 目录里检索文件哈希。 内核侧再加一道 BCrypt SHA-256 映像白名单门禁。
